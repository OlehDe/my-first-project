🛡️ Valheimopedia
Інформаційний веб-портал | Енциклопедія + Навігатор для Valheim

Valheimopedia — це сучасний веб-застосунок, створений для дослідників скандинавських земель Valheim. Проєкт поєднує в собі повноцінну енциклопедію з детальною інформацією про ігрові механіки та інтерактивного навігатора, який допомагає гравцям ефективно освоювати гру.

🎯 Мета проєкту
Створити єдиний зручний простір, де гравець зможе:

Швидко знайти інформацію про будь-який ресурс, зброю, істоту чи біом.

Візуалізувати «дерево» крафту та прогресу.

Отримувати підказки щодо дослідження світу та подолання босів.

✨ Ключові особливості
📖 Енциклопедія

Детальні статті про істот (вороги, друзі, боси).

Каталог зброї, броні, інструментів та їжі з характеристиками.

Опис біомів, локацій та їхніх небезпек.

Інтерактивні таблиці крафту з вимогами до ресурсів.

🧭 Навігатор

Покрокові гайди для проходження.

Візуалізація зв’язків: який ресурс потрібен для чого.

Рекомендації щодо порядку дослідження біомів та босів.

⚡ Зручність

Повнотекстовий пошук.

Адаптивний дизайн (коректно відображається на ПК, планшеті та мобільному).

Швидке завантаження сторінок.

🛠️ Технології
Цей розділ варто доповнити залежно від вашого стеку.

Frontend: React / Vue / Angular (або просто HTML/CSS/JS)

Backend: Node.js / Python (Django/FastAPI) / PHP

База даних: PostgreSQL / MongoDB

Стилі: TailwindCSS / SCSS / Bootstrap

API: Взаємодія з ігровими даними через парсинг або власну структуру

🚀 Статус розробки
Проєкт знаходиться на стадії розробки. Наразі реалізовано базову структуру енциклопедії та прототип навігатора.

Плани:

Додати інтерактивну карту світу.

Реалізувати систему «Мій інвентар» для відстеження прогресу гравця.

Інтеграція з калькулятором виплавки металу та часу приготування їжі.
